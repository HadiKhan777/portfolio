How
01
Read the spec, write the code

RFC 6455 for WebSocket framing. POSIX namespace APIs for container isolation. The full backward pass derivation for BatchNorm. Understanding the substrate is the work, not the abstraction on top of it.

02
Zero dependencies forces clarity

When you cannot install a library, you are forced to understand what the library actually does. distkv does not use Redis. neuralkit does not use PyTorch. Every line exists because it needs to.

03
Benchmarks are proof, not decoration

19,312 ops/sec on PING. 7,240 on SET with replication. WAL replay after SIGKILL -9. Numbers come from running the code against real load, not from estimating what should be possible.
