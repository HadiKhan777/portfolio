# portfolio

Personal portfolio site — single HTML file, no build step, no dependencies.

**Live:** https://hadikhan777.github.io/portfolio/

## Projects showcased

| Repo | What it is |
|------|-----------|
| [distkv](https://github.com/HadiKhan777/distkv) | Distributed KV store — custom TCP protocol, WAL persistence, streaming replication |
| [neuralkit](https://github.com/HadiKhan777/neuralkit) | Neural network framework — NumPy only, BatchNorm, GELU, AdamW, cosine LR |
| [nanohttp](https://github.com/HadiKhan777/nanohttp) | HTTP/1.1 + WebSocket (RFC 6455) + JWT HS256 + SSE server |
| [gitlet](https://github.com/HadiKhan777/gitlet) | Git clone — merge, reset, stash, tags, LCS unified diff |
| [tui](https://github.com/HadiKhan777/tui) | Terminal UI framework — ANSI escape codes, 30fps render loop, widget library |
| [kontainer](https://github.com/HadiKhan777/kontainer) | Container runtime — Linux namespaces, cgroup v2, no Docker |
| [pipecraft](https://github.com/HadiKhan777/pipecraft) | CI/CD engine — parallel jobs, dependency graph, retry, live TUI |

## Stack

Plain HTML, CSS, and vanilla JS. Opens directly in a browser — no npm, no bundler, no framework.
